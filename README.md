# MechashevMechadash

אפליקציית Flask שמועלית ל-AWS Elastic Beanstalk, מאחורי CloudFront.

**האתר:** https://mechashev-mechadash.com/

- CloudFront: `d4b39evjyvuy9.cloudfront.net` (תעודת SSL מ-ACM באזור us-east-1)
- Elastic Beanstalk: http://mechashevmechadash-env.eba-d3bvj2jb.il-central-1.elasticbeanstalk.com/
- משתנה סביבה `FORCE_HTTPS=true` מסמן את עוגיית ההתחברות כמאובטחת (Secure)
